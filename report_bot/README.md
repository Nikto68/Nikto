# ربات گزارشات (Report Bot)

پروژه‌ای کاملاً جدا از بقیه‌ی فایل‌های این ریپو (ربات فروشگاه/آپلودر) — یک ربات تلگرامیِ مستقل با PHP، برای گرفتنِ گزارش (عکس/ویدیو) از کاربر، بررسیِ آن در یک گروه/تاپیک، و در صورتِ تایید، انتشارِ خودکار در یک کانال.

## جریانِ کار

1. کاربر `/start` می‌زند → متنِ خوش‌آمد (+ عکسِ اختیاری) با دکمه‌های شیشه‌ای: **📖 راهنما**، **📮 ارسال گزارش**، **🎧 ارتباط با پشتیبانی**، **👤 حساب کاربری**.
2. با زدنِ «ارسال گزارش»، ربات منتظرِ متن/عکس/ویدیو می‌ماند. کاربر می‌فرستد → قبل از هر چیز از خودش تاییدِ نهایی گرفته می‌شود («این محتوا ارسال شود؟» + ✅/❌). فقط با زدنِ ✅ محتوا عیناً به گروه/تاپیکِ گزارش می‌رود.
3. زیرِ همان پست در گروه: دکمه‌های تگ (اگر تعریف شده باشند) + **✅ تایید** / **❌ رد**.
4. با زدنِ تایید: محتوا مستقیماً (از رویِ پیامِ اصلیِ کاربر، نه نسخه‌ی گروه) به کانالِ مقصد فرستاده می‌شود، همراهِ تگِ انتخابی. کاربر و پستِ گروه هر دو به‌روزرسانی می‌شوند.
5. با زدنِ رد: چیزی منتشر نمی‌شود؛ فقط وضعیت در گروه و برایِ کاربر ثبت/اطلاع‌رسانی می‌شود.
6. «ارتباط با پشتیبانی»: پیامِ کاربر به گروه/تاپیکِ پشتیبانی می‌رود؛ هر مدیری با **ریپلای‌کردن** روی همان پیام، مستقیم به کاربر پاسخ می‌دهد.
7. «👤 حساب کاربری»: شناسه‌ی عددی، نام، یوزرنیم، تاریخِ عضویت و تعدادِ گزارش‌ها (کل/تایید/رد/در انتظار) را نشان می‌دهد.
8. «📖 راهنما»: متن + عکسِ دلخواهِ مدیر را می‌فرستد (پیامِ مستقل، نه ادیتِ صفحه‌ی استارت).
9. مدیر می‌تواند در گروهِ گزارش، روی پستِ یک گزارش **ریپلای** کند؛ متنش مستقیم برایِ فرستنده‌ی همان گزارش ارسال می‌شود (جدا از تایید/رد).

برایِ جلوگیری از شلوغ‌شدنِ چت، ناوبریِ ربات (دکمه‌ها، منوها، تاییدیه‌ها) همیشه همان پیام را ادیت می‌کند، نه پیامِ تازه — به‌جز رویدادهایِ ناهم‌زمانِ واقعی (پاسخِ پشتیبانی، ریپلایِ مدیر روی یک گزارش) که پیامِ تازه‌اند.

همه‌ی این تنظیمات از داخلِ خودِ ربات مدیریت می‌شوند: دستورِ `/admin` یا دکمه‌ی «⚙️ پنل مدیریت» زیرِ `/start` (فقط برای آیدی‌های داخلِ `REPORT_ADMIN_ID` / `REPORT_ADMIN_IDS`).

### پنلِ مدیریت (داخلِ ربات)

- **🏷 مدیریتِ تگ‌ها** — افزودن/حذفِ برچسب‌هایی که زیرِ هر گزارش در گروه، دکمه می‌شوند.
- **⭐ ایموجی‌های پریمیوم** — برای هرکدام از ۹ جایگاه (ارسال گزارش، پشتیبانی، حساب کاربری، راهنما، بازگشت، تایید، رد، ابتدایِ پیامِ خوش‌آمد، پنلِ مدیریت)، یک ایموجیِ پریمیوم قابلِ تنظیم است: مدیر (با تلگرامِ پریمیوم) پیامی حاویِ همان ایموجی می‌فرستد؛ ربات آیدیِ آن را از `entities` پیام می‌خواند و ذخیره می‌کند.
- **🎨 رنگِ دکمه‌ها** — برایِ همان جایگاه‌ها (به‌جز راهنما/بازگشت که خنثی می‌مانند) رنگ را می‌شود دستی به آبی/سبز/قرمز/بدونِ رنگ تغییر داد؛ این انتخاب همیشه رویِ رنگِ پیش‌فرضِ کد اولویت دارد.
- **✏️ متن‌های ربات** — پیامِ خوش‌آمد + تکِ‌تکِ متن‌هایی که ربات در مسیرِ گزارش/پشتیبانی/راهنما نشان می‌دهد (پرامپت‌ها، خطاها، تاییدیه‌ها)، همه از همین‌جا قابلِ ویرایش‌اند؛ هرکدام دکمه‌ی «↩️ پیش‌فرض» هم دارد.
- **🖼 عکسِ پیامِ خوش‌آمد** و **📖 عکسِ راهنما** — هرکدام مستقل، قابلِ تنظیم/حذف.
- **👥 گروه/تاپیکِ گزارش** — ربات را ادمینِ گروه کنید، بعد داخلِ همان تاپیک (یا خودِ گروه) دستورِ `/setreporttopic` را بفرستید.
- **📨 گروه/تاپیکِ پشتیبانی** — همان‌طور، با دستورِ `/setsupporttopic`. می‌تواند همان گروهِ گزارش (تاپیکِ دیگر) یا گروهی کاملاً جدا باشد.
- **📢 کانالِ مقصد** — ربات را ادمینِ کانال کنید، بعد یک پیام از همان کانال را برایِ ربات فوروارد کنید (یا آیدی/یوزرنیمِ کانال را تایپ کنید).
- **ℹ️ وضعیتِ تنظیمات** — خلاصه‌ی همه‌ی مقادیرِ بالا.

## رنگ و آیکونِ دکمه‌ها (Bot API 9.4+)

دکمه‌ها رنگ دارند (`style`: `primary` آبی / `success` سبز / `danger` قرمز)، پیش‌فرض کد یا هرچه از «🎨 رنگ دکمه‌ها» ست شود. وقتی برایِ یک جایگاه ایموجیِ پریمیوم تنظیم شده باشد، همان آیکونِ واقعی (نه فقط کاراکترِ ساده) با `icon_custom_emoji_id` روی دکمه نشان داده می‌شود — این ویژگی از Bot API 9.4 (فوریه‌ی ۲۰۲۶) پشتیبانی می‌شود. طبقِ مستنداتِ تلگرام، آیکونِ ایموجیِ پریمیوم روی دکمه فقط وقتی نمایش داده می‌شود که مالکِ ربات (کسی که رباتو در BotFather ساخته) تلگرام پریمیومِ فعال داشته باشد، یا ربات یوزرنیمِ خریداری‌شده از Fragment داشته باشد؛ وگرنه تلگرام آیکون را نادیده می‌گیرد (دکمه بدونِ آیکون، ولی با رنگِ style، نمایش داده می‌شود).

## محدودیت‌های شناخته‌شده

- هر پیام (متن/عکس/ویدیو) یک گزارشِ جداگانه می‌شود؛ اگر کاربر یک آلبوم (چند عکس با هم) بفرستد، هرکدام جدا جدا برایِ بررسی می‌رود، نه یک‌جا.
- دکمه‌های تایید/رد و انتخابِ تگ فقط برایِ آیدی‌هایِ داخلِ `REPORT_ADMIN_ID`/`REPORT_ADMIN_IDS` کار می‌کنند (نه هر عضوِ گروه).

## نصب

### ۱) تنظیمات

```bash
cp report_bot/config.local.example.php report_bot/config.local.php
```

و داخلش:

```php
define('REPORT_BOT_TOKEN', 'توکنِ رباتِ شما');
define('REPORT_ADMIN_ID', آیدیِ_عددیِ_مدیر);
define('REPORT_WEBHOOK_SECRET', 'یک رشته‌ی تصادفیِ بلند'); // مثلا: php -r "echo bin2hex(random_bytes(32));"
```

این فایل در `.gitignore` است و هرگز نباید به گیت برود — دقیقاً به همین دلیل که توکن داخلش است.

### ۲) ثبتِ Webhook

بعدِ آپلودِ پوشه روی هاست (با HTTPS معتبر)، یکی از این دو راه:

**اگر SSH/CLI دارید:**
```bash
php report_bot/tools/set_webhook.php https://yourdomain.com/report_bot/webhook.php
```

**اگر فقط هاستِ اشتراکی/FTP دارید (بدونِ SSH):** همین آدرس را در مرورگر باز کنید (مقدارِ `key` را از `REPORT_WEBHOOK_SECRET` داخلِ `config.local.php` بردارید):
```
https://yourdomain.com/report_bot/tools/set_webhook.php?url=https://yourdomain.com/report_bot/webhook.php&key=REPORT_WEBHOOK_SECRETِ‌شما
```
خروجی باید `"ok": true` باشد. بدونِ `key`ِ درست این آدرس هیچ کاری نمی‌کند، ولی بهتر است بعدِ استفاده، پوشه‌ی `tools/` را از روی هاست پاک یا rename کنید.

### ۳) گروه و کانال

- ربات را با دسترسیِ ارسالِ پیام، ادمینِ گروهِ بررسی و کانالِ مقصد کنید.
- داخلِ ربات، از `/admin` استفاده کنید تا گروه/تاپیک و کانال را طبقِ راهنماییِ خودِ پنل تنظیم کنید.

### نیازمندی‌ها

- PHP ≥ 7.4 با افزونه‌های `sqlite3` و `curl`.
- یک دامنه‌ی HTTPS معتبر (لازمه‌ی webhook تلگرام).

## ساختارِ فایل‌ها

```
report_bot/
  bootstrap.php              تنظیمات + require همه‌ی lib ها
  webhook.php                نقطه‌ی ورودِ webhook (آدرسی که به تلگرام می‌دهید)
  config.local.example.php   نمونه‌ی تنظیمات (کپی کنید به config.local.php)
  lib/                       دیتابیس، کلاینتِ Bot API، entities، ایموجی، رنگِ دکمه (style.php)، متن‌های ربات (texts.php)، کپشن‌ها، کیبوردها، ادیت‌این‌پلیس (screen.php)
  handlers/                  منطقِ هر بخش: start، account، guide، report، support، admin
  tools/set_webhook.php      ثبتِ webhook
  data/                      دیتابیسِ SQLite (گیت‌ایگنور)
```
