# 🎨 ربات ساخت پک ایموجی پریمیوم اختصاصی (PHP + Mini App)

کاربر ربات را استارت می‌کند، دکمه **«🎨 ساخت ایموجی»** (هم در پیام و هم دکمه منوی کنار کیبورد) مینی‌اپ را باز می‌کند؛
متن دلخواهش را می‌نویسد، رنگ/فونت/اندازه/ارتفاع را تنظیم می‌کند، قالب‌ها را انتخاب می‌کند و ربات در چند ثانیه
یک **پک Custom Emoji واقعی تلگرام** (`t.me/addemoji/...`) به نام خود کاربر می‌سازد.

## ✨ امکانات

**🖼 پک لوگو (برای برندها، کانال‌ها و پروژه‌های کریپتو)**
- در مینی‌اپ بین «متن» و «لوگو» سوییچ کنید و لوگو را آپلود کنید (PNG/JPG/WEBP تا ۵MB)
- پس‌زمینه ساده (مثلاً سفید در JPG) خودکار حذف و حاشیه‌های خالی بریده می‌شود
- لوگو روی همه قالب‌ها می‌نشیند: سپر، نشان، سکه، الماس، جام، کاراکترهای تابلو به دست، روبان‌ها و ...
- ۴ حالت رنگ لوگو: رنگ اصلی لوگو / تک‌رنگ ۱ / تک‌رنگ ۲ / دو رنگ — مثلاً سپر مشکی با لوگوی سبز
- قالب‌های **نمودار کریپتو**: میله‌های سبز صعودی و قرمز نزولی با سکه لوگو (نسخه متحرک: میله‌ها رشد می‌کنند و سکه شناور است)
- هر کاربر فقط به لوگوهای خودش دسترسی دارد؛ ۱۲ لوگوی آخر هر کاربر نگه داشته می‌شود

**قالب‌های ترند متحرک (۱۰۶ قالب — همه زنده و متحرک)**
- 🔥 **ترند متحرک** (۴۴): جام، سکه، کیسه پول، الماس، تاج، انگشتر، موشک، آتش، کادو، قلب، کارت، اسلات، ... —
  متن روی خود شیء نوشته می‌شود و هر کدام حرکت مخصوص خودش را دارد (درخشش، چرخش سکه، ضربان، لرزش، شناور، ...)
- 🐾 **تابلو به دست** (۳۰): گربه، سگ، قورباغه، پاندا، روباه، آدم‌فضایی، ربات، 😎، 🤑، ... که تابلوی اسم را با دست گرفته‌اند
  و از پشت تابلو **سرک می‌کشند** (تابلو ثابت، کاراکتر بالا و پایین می‌رود و تکان می‌خورد)
- 🎀 **روبان‌دار** (۳۲): رز، رنگین‌کمان، اژدها، یونیکورن، شمشیر، ... که **بالای روبان اسم معلق‌اند**
- دکمه 🎨 در مینی‌اپ: خود قالب‌ها هم به **رنگ انتخابی کاربر** درمی‌آیند (مثل کالکشن‌های تک‌رنگ ربات‌های معروف)
- طرح‌ها از Microsoft Fluent Emoji (مجوز MIT — استفاده تجاری آزاد) — متن مجوز در `assets/art`
- بعد از ساخت، ربات سعی می‌کند ایموجی‌های تازه را داخل پیامش نشان دهد (`tg-emoji`؛ فقط اگر صاحب ربات پریمیوم باشد، وگرنه پیام معمولی)

**مینی‌اپ (کاملاً انگلیسی، چپ‌به‌راست)**
- رابط مینی‌اپ و پیام‌های ربات برای کاربران انگلیسی است؛ پنل مدیریت `/admin` فارسی می‌ماند
- متن **انگلیسی** (پیش‌فرض؛ ادمین می‌تواند از تنظیمات «اجازه متن فارسی» را روشن کند) با پیش‌نمایش زنده روی همه قالب‌ها
- دو رنگ (رنگ اصلی/رنگ دوم) + ترکیب‌های آماده + رنگ دلخواه،
  ۱۶ فونت: Montserrat، Unbounded، Lilita، Luckiest Guy، Titan، Bangers، Russo، Rubik Mono، Black Ops، Bungee، Marker، Pixel، Pacifico، وزیر، لاله‌زار، ساحل
- اسلایدر «اندازه» و «ارتفاع» متن، دسته‌بندی‌های تاشو، «انتخاب همه»، شماره‌گذاری و تیک قالب‌ها
- ساخت پک جدید یا **افزودن به پک‌های قبلی** (تا ۲۰۰ ایموجی)، نوار پیشرفت زنده، دکمه «افزودن به تلگرام»
- «پک‌های من» (باز کردن/افزودن/حذف)، سکه + خرید با **Telegram Stars ⭐**، هدیه روزانه، لینک دعوت
- پنل مدیریت قالب‌ها برای ادمین: آپلود تصویر (مثلاً شخصیت پپه با تابلو)، **کشیدن کادر متن روی تصویر**،
  چرخش، رنگ‌آمیزی خودکار با رنگ‌های کاربر (دو رنگ / حفظ سایه‌روشن)، دورخط، سایه، افکت حرکتی، لایه روی متن

**موتور ساخت**
- ۱۰۶ قالب ترند متحرک + ۴۴ قالب شکلی (۱۷ متحرک + ۲۷ ثابت) — جمعاً ۱۵۰ قالب
- ۱۷ افکت حرکتی: سرک کشیدن، معلق، رشد نمودار، پرچم مواج، ضربان قلب، سکه چرخان، درخشش، نئون، رنگین‌کمان، پرش، لرزش، ...
- **شکل‌دهی کامل فارسی** (اتصال حروف، لا، نیم‌فاصله، اعداد فارسی، متن ترکیبی فارسی/انگلیسی) — GD به‌تنهایی این کار را نمی‌کند
- خروجی دقیقاً طبق استاندارد تلگرام: ثابت PNG ‏100×100، متحرک WEBM/VP9 با شفافیت، ۲ ثانیه، ۳۰fps، زیر ۶۴KB
- صف ساخت در پس‌زمینه با قفل اتمیک، محدودیت هم‌زمانی، برگشت خودکار سکه در خطا، بازیابی کارهای گیرکرده

**ربات و مدیریت** (`/admin`)
- آمار کامل، پیام همگانی (کپی هر نوع پیام، در پس‌زمینه با رعایت محدودیت تلگرام)
- مدیریت کاربر: مسدود/رفع مسدودی، افزودن/کسر سکه، مشاهده پرداخت‌ها و دعوت‌ها
- تنظیمات: قیمت هر ایموجی، سکه شروع، هدیه روزانه، پاداش دعوت، سقف ساخت روزانه، طول متن، پسوند عنوان پک،
  **جوین اجباری کانال**، حالت تعمیر
- بازگشت وجه ستاره: `/refund <charge_id>`

**امنیت**
- اعتبارسنجی امضای `initData` مینی‌اپ (HMAC-SHA256) + انقضا در هر درخواست API
- وبهوک با `secret_token`، حذف آپدیت‌های تکراری، محدودیت نرخ درخواست برای هر کاربر
- تمام کوئری‌ها Prepared Statement، خروجی HTML همیشه escape، مینی‌اپ بدون `innerHTML` برای داده
- پرداخت‌ها idempotent (هر `charge_id` فقط یک‌بار)، بررسی مبلغ/ارز/مالک فاکتور در pre-checkout
- تصاویر آپلودی دوباره رمزگذاری می‌شوند (حذف متادیتا/فایل‌های مخرب) و خارج از وب ذخیره می‌شوند

## ⚠️ قبل از هر چیز: توکن را عوض کنید

توکن ربات را در چت فرستاده‌اید؛ هر جایی غیر از `config.php` روی سرور خودتان «لو رفته» حساب می‌شود.
در [@BotFather](https://t.me/BotFather): `/mybots` → ربات → **API Token** → **Revoke current token** و توکن جدید را فقط در `config.php` بگذارید.
(`config.php` در `.gitignore` است و هرگز داخل گیت نمی‌رود.)

## 📋 پیش‌نیازها

| مورد | توضیح |
|---|---|
| PHP | نسخه 8.1 یا بالاتر |
| افزونه‌ها | `gd` (با FreeType)، `curl`، `mbstring`، `pdo_sqlite` (یا `pdo_mysql`)، `intl` (اختیاری) |
| ffmpeg | با `libvpx-vp9` — فقط برای ایموجی متحرک. اگر نباشد قالب‌های متحرک خودکار مخفی می‌شوند |
| دامنه HTTPS | برای وبهوک و مینی‌اپ الزامی است |
| `proc_open` | برای اجرای ffmpeg باید در `disable_functions` نباشد |

## 🚀 نصب

1. پوشه `emoji-bot` را روی هاست آپلود کنید.
   - بهترین حالت: ریشه دامنه/ساب‌دامین را روی پوشه `public` بگذارید.
   - اگر نمی‌شود، کل پوشه را آپلود کنید؛ فایل‌های `.htaccess` دسترسی به همه‌چیز جز `public` را می‌بندند (Apache/LiteSpeed).
     روی **Nginx** حتماً این را اضافه کنید:
     ```nginx
     location ~ ^/emoji-bot/(src|storage|bin|assets|tests|config\.php) { deny all; }
     ```
2. تنظیمات:
   ```bash
   cp config.example.php config.php
   ```
   در `config.php` فقط این دو را پر کنید: `bot_token` (توکن جدید) و `secret`
   (یک رشته تصادفی ۳۲+ کاراکتری: `php -r "echo bin2hex(random_bytes(24));"`).
   آیدی مدیر `6595849261` و دامنه شما از قبل تنظیم شده‌اند:

   | مورد | آدرس (وقتی پوشه `emoji-bot` در ریشه دامنه است) |
   |---|---|
   | `base_url` | `https://nikto.s14.telviprobot.top/emoji-bot/public` |
   | وبهوک (خودکار ثبت می‌شود) | `https://nikto.s14.telviprobot.top/emoji-bot/public/webhook.php` |
   | صفحه نصب | `https://nikto.s14.telviprobot.top/emoji-bot/public/setup.php` |
   | مینی‌اپ | `https://nikto.s14.telviprobot.top/emoji-bot/public/app/` |

   اگر ریشه دامنه را مستقیماً روی پوشه `public` گذاشتید، `base_url` را `https://nikto.s14.telviprobot.top` کنید.
3. پوشه `storage` باید قابل نوشتن باشد (`chmod -R 775 storage`).
4. نصب: آدرس `https://.../public/setup.php` را باز کنید و `secret` را وارد کنید
   (یا با SSH: `php bin/setup.php`). این مرحله وبهوک، دکمه منوی مینی‌اپ، دستورات و توضیحات ربات را تنظیم می‌کند و محیط سرور را چک می‌کند.
5. **Cron** هر دقیقه (برای پیام همگانی، صف ساخت و پاک‌سازی):
   ```
   * * * * * php /path/to/emoji-bot/bin/worker.php
   ```
   اگر Cron با PHP CLI ندارید، آدرسی که setup نمایش می‌دهد (`cron.php?key=...`) را در یک وب‌کرون هر دقیقه صدا بزنید.
6. در BotFather برای دکمه **Open** بالای پروفایل/چت ربات:
   `/mybots` → ربات → **Bot Settings** → **Configure Mini App** → Enable → آدرس `https://nikto.s14.telviprobot.top/emoji-bot/public/app/`
7. در تلگرام `/start` بزنید. برای پنل مدیریت: `/admin`

> حالت بدون وبهوک (برای تست روی سیستم خودتان): `php bin/setup.php --polling && php bin/poll.php`
> (مینی‌اپ همچنان به یک آدرس HTTPS نیاز دارد.)

## 🧩 افزودن قالب اختصاصی (مثلاً پپه و پرچم)

در مینی‌اپ (کاربر ادمین) آیکون ⚙️ → **افزودن قالب جدید**:
1. تصویر PNG مربعی با پس‌زمینه شفاف آپلود کنید (بهتر: طرح سیاه‌وسفید/خطی تا با رنگ کاربر رنگ شود).
2. کادر آبی را روی جای متن (مثلاً تابلو یا پرچمی که پپه دستش گرفته) بکشید و اندازه/چرخش را تنظیم کنید.
3. «رنگ‌آمیزی تصویر»:
   - **دو رنگ**: قسمت‌های تیره ← رنگ اصلی کاربر، روشن ← رنگ دوم (مثل پک‌های نمونه‌ای که فرستادید)
   - **حفظ سایه‌روشن**: برای طرح‌های رنگی
   - **رنگ اصلی تصویر**: بدون تغییر
4. رنگ متن، دورخط، افکت حرکتی (مثلاً «موج پرچم» یا «تپش») و دسته‌بندی را انتخاب کنید، «فعال» را روشن و ذخیره کنید.
   اگر بخشی از تصویر باید **روی** متن باشد (مثل انگشت‌های دست)، آن را به‌عنوان «لایه روی متن» آپلود کنید.

> ⚖️ فقط تصاویری را آپلود کنید که حق استفاده از آن‌ها را دارید. ربات هیچ تصویر شخص ثالثی را همراه ندارد.

## 💰 سکه و ستاره

- پیش‌فرض ساخت **رایگان** است (`قیمت هر ایموجی = 0`). از `/admin` → تنظیمات قیمت بگذارید.
- بسته‌های خرید در `config.php` → `stars_packages`. پرداخت با Telegram Stars نیازی به درگاه ندارد.
- ادمین‌ها همیشه رایگان می‌سازند و سقف روزانه ندارند.

## 📐 استاندارد فایل‌ها (طبق Bot API 10.3)

- `createNewStickerSet` با `sticker_type=custom_emoji`، حداکثر ۵۰ ایموجی اول؛ بقیه با `addStickerToSet` (تا ۲۰۰)
- نام پک: `e..._by_<botusername>`، فقط حروف انگلیسی/عدد/`_`
- ثابت: PNG ‏100×100 — متحرک: WEBM، VP9، `yuva420p` (شفاف)، `-auto-alt-ref 0`، ۲ ثانیه، ۳۰fps، بدون صدا، ≤ ۶۴KB
- ایموجی سفارشی در پیام‌ها فقط برای کاربران **Telegram Premium** قابل استفاده است (مینی‌اپ به کاربران غیرپریمیوم تذکر می‌دهد).

## 🧪 تست

```bash
tests/run.sh [/path/to/ffmpeg]
```
یک سرور جعلی Bot API (که فایل‌ها را مثل تلگرام اعتبارسنجی می‌کند) + سرور PHP بالا می‌آورد و ۹۰ سناریو را تست می‌کند:
استارت/دعوت/هدیه، پنل مدیریت، جوین اجباری، امضای initData، پیش‌نمایش، پرداخت ستاره، ساخت/افزودن/حذف پک،
برگشت سکه در خطا، پک لوگو (آپلود، حذف پس‌زمینه، مالکیت)، قالب اختصاصی، پیام همگانی، حالت تعمیر و مسدودسازی.

```
emoji-bot/
├── config.example.php     ← کپی به config.php
├── bootstrap.php
├── public/                ← فقط این پوشه باید از وب در دسترس باشد
│   ├── webhook.php  api.php  setup.php  cron.php
│   └── app/               ← مینی‌اپ (index.html, app.js, app.css, fonts)
├── src/
│   ├── Bot/               ← Handler، Admin، Payments، Membership، Broadcaster، Texts
│   ├── Render/            ← Shaper (فارسی)، Fonts، TextRenderer، Builtins، CustomTemplate، Renderer، VideoEncoder
│   ├── Packs/             ← PackService (Bot API استیکر)، Jobs (صف)
│   ├── Api/               ← API مینی‌اپ + مدیریت قالب
│   └── Db, Telegram, WebAppAuth, RateLimiter, Settings, Users, Worker, Setup
├── bin/                   ← setup.php، worker.php، poll.php
├── assets/fonts/          ← فونت‌ها (OFL / Apache) + مجوزها
├── assets/art/            ← طرح‌های سه‌بعدی قالب‌های ترند (Fluent Emoji، MIT)
├── storage/               ← دیتابیس SQLite، کش، لوگوهای کاربران، لاگ (از وب بسته)
└── tests/
```

## 🛠 رفع اشکال

| مشکل | راه‌حل |
|---|---|
| ربات جواب نمی‌دهد | `setup.php` را دوباره اجرا کنید و «آخرین خطا»ی وبهوک را ببینید؛ `storage/logs` را چک کنید |
| قالب‌های متحرک نیستند | ffmpeg نصب نیست یا `proc_open` غیرفعال است (setup گزارش می‌دهد) |
| «نشست نامعتبر» در مینی‌اپ | مینی‌اپ را ببندید و دوباره باز کنید (initData بیش از ۲۴ ساعت اعتبار ندارد) |
| «ابتدا ربات را استارت کنید» | کاربر باید حداقل یک‌بار `/start` زده باشد |
| جوین اجباری کار نمی‌کند | ربات باید در کانال **ادمین** باشد |
